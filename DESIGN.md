# Reading before chrome

A native reading window with the quiet hierarchy of a typeset book. The actual book occupies the main surface; one native toolbar holds open, contents, and appearance. No library dashboard or invented sample content.

- Warm paper #F8F5EF, ink #302E29, secondary #777267, restrained olive #5B6548. Dark paper #20221F and ink #E6E2D8 for evening reading.
- New York / Georgia serif for the empty-state title and book body. Native system type for controls and contents, preserving Mac conventions.
- Body 20px by default, 1.8 line height, maximum 68 characters, with generous side margins that contract in small windows.
- A 270px contents sidebar with a book title, author, and a plain list of sections. Selected chapters use a quiet tinted background. Sidebar can disappear completely.
- Real empty, loading, error, and reading states. Keyboard access, native file dialog, drag and drop, selectable text, and visible navigation boundaries.
- Text selection reveals a compact native toolbar with four highlight colors and an Add note action. The saved-item sidebar uses plain rows with quoted passages. Clicking an inline highlight opens its attached note. All annotation controls follow the selected language.

References read: https://github.com/Hmbown/taste/blob/main/SKILL.md and references/DOMAINS.md; https://github.com/pbakaus/impeccable/blob/main/.agent/skills/impeccable/SKILL.md and reference/{init,new-work,craft-floor}.md. Native Mac reading conventions and the actual local EPUB metadata ground the decisions.
